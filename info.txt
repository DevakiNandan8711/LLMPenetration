HackSynth – An Autonomous LLM-Driven
Penetration Testing System
Abstract
HackSynth is an autonomous penetration-testing system powered by Large Language Models
(LLMs) that performs multi-step cybersecurity tasks without human intervention. Inspired by
Capture-the-Flag (CTF) challenges, the system behaves like an ethical hacker capable of
planning attack sequences, executing terminal commands in a sandboxed environment, and
summarizing results to determine the next logical action. HackSynth integrates two core
LLM-based modules—Planner and Summarizer—connected through an iterative
decision-making loop. The backend is implemented using FastAPI, Docker-based execution
environments, and optional database logging (PostgreSQL/MongoDB). The frontend, developed
using React, provides real-time logs, command history, performance metrics, and final flag
results. This paper presents the system architecture, literature review, methodology,
applications, and implementation strategies for building a safe and effective autonomous
cybersecurity agent.
Introduction
Modern cybersecurity requires rapid vulnerability assessment and penetration testing, tasks that
often demand expert knowledge and manual effort. Recent advancements in LLMs like GPT-4o,
Llama-3, Qwen2, Mixtral, and Phi-3 have enabled systems to mimic human reasoning, making
them suitable for guided and autonomous decision-making. HackSynth leverages these
capabilities to automate ethical hacking workflows by generating terminal commands, analyzing
outputs, and performing step-wise infiltration tasks in CTF-like environments.
HackSynth addresses a major gap in cybersecurity automation: the inability of existing tools to
autonomously plan multi-step attacks using natural language reasoning. With an LLM-powered
planner, summarizer, and a secure execution loop, HackSynth provides a controlled, safe, and
intelligent penetration testing agent for research, training, and evaluation.

Existing Work and Limitations
1. Manual Penetration Testing
● Requires domain experts
● Time-consuming
● Susceptible to human error
● Not scalable
2. Scripted / Automated Tools (e.g., Metasploit, Nmap automation)
● Only perform predefined actions
● Cannot reason or adapt
● No multi-step logical planning
3. ML-Based Cyber Tools
● Focus on anomaly detection
● Not capable of real penetration workflows
● Do not generate commands or interpret terminal output
4. Prior LLM Tools
● Provide suggestions only
● No secure sandbox execution
● No agent loop
● Cannot autonomously complete CTF tasks
→ The limitation: Missing a fully autonomous, safe, and intelligent penetration-testing
agent.
Proposed Work: HackSynth Autonomous LLM Pentesting
Agent
HackSynth introduces a two-module LLM design:
1️⃣Planner Module
● Thinks like a hacker
● Generates next attack command
● Uses summarized history + environment description
Example output:
nmap -sV 10.0.0.5
●
2️⃣Summarizer Module
● Reads raw terminal output
● Extracts only useful details
● Removes noise
● Returns structured summary back to Planner
Core Autonomous Loop
1. Planner generates next command
2. Executor runs command inside Docker container
3. Summarizer interprets output
4. Loop repeats until:
○ Flag found
○ Maximum steps reached
○ Dead end or error detected
Problem Statement
“To design and implement an autonomous LLM-driven penetration-testing system that can plan,
execute, summarize, and iteratively solve multi-step CTF challenges in a secure sandboxed
environment without human intervention.”
Objectives
● Develop an AI agent that behaves like an ethical hacker
● Automate terminal-based multi-step penetration testing
● Use LLMs for reasoning, planning, and summarization
● Execute commands safely using Docker sandbox
● Provide real-time logs and visualization through React
● Evaluate model performance (accuracy, token usage, safety, hallucinations)
● Reduce manual effort in cybersecurity training
● Support multiple LLMs via API or local models
Working Model / Architecture
1. React Frontend
● Challenge loader
● Agent control dashboard
● Live logs console
● Command history
● Final flag viewer
● Analytics (steps, tokens, errors)
2. FastAPI Backend
● /planner → Generates next command
● /executor → Runs command inside Docker container
● /summarizer → Summarizes last output
● /run-loop → Full autonomous agent cycle
● Safety checks + execution limits
3. Docker Sandbox
● Isolated environment
● Restricted network access
● Executes commands safely
4. Databases (Optional: PostgreSQL / MongoDB)
● Store logs
● Store command sequences
● Token usage analytics
● Challenge runs history
5. LLMs (GPT-4o, Llama-3, Phi-3, Qwen2, Mixtral)
● Multi-model agent
● API or self-hosted

Conclusion
HackSynth demonstrates the potential of Large Language Models in autonomous penetration
testing by enabling AI to plan and execute multi-step attacks in secure sandboxed
environments. Using its Planner and Summarizer modules, HackSynth mirrors human ethical
hacking behavior while maintaining safety and reproducibility. The combination of FastAPI,
Docker sandboxing, React-based visualization, and multi-model LLM support enables a
complete end-to-end research platform for experimenting with autonomous cybersecurity
agents. This work highlights the feasibility and risks of LLM-driven cyber systems while
contributing a foundation for future research in AI-based security automation.
